## 🛠️ 在造的东西

### 🌐 [iceBrowser](https://github.com/ice-wocker/iceBrowser) — Android 浏览器
- 纯 Java / 单 dex / 0 依赖
- APK **81 KB**（业界平均 30 MB+，小 400 倍）
- 真正的多 Tab 系统 + 4 引擎切换（ice/Bing/Google/DDG）
- 内置 AdBlocker / 阅读模式 / 无痕模式

### 🔌 [iceProxy](https://github.com/ice-wocker/iceProxy) — AI API 代理
- Cloudflare Workers / 单文件 ~460 行
- **28+ 顶级免费模型**（Qwen3-Max, GLM-5.3, DeepSeek-V4, gpt-oss-120b, Llama-4）
- OpenAI 协议兼容，Cline/Cursor/ChatBox 直接用
- 1 个 token 调 11+ provider，~每天数千次顶级模型

### 📚 [iceReading](https://github.com/ice-wocker/iceReading) — Android EPUB 阅读器
- 纯 Java / 0 依赖 / 单 dex
- APK < 100 KB
- 零云同步 / 零追踪 / 零广告
- 阅读模式 / 4 主题

### 🎵 [MusicFusion](https://github.com/ice-wocker/MusicFusion) — 聚合音乐播放器
- 900 万+ 合法曲目 + 2945 个电台
- Audius / Internet Archive / RadioBrowser / SomaFM 四源聚合
- 全离线缓存 / 0 跟踪
